# Proyecto: Aplicación móvil para predicción de enfermedades cardiovasculares

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una aplicación móvil que permite analizar datos médicos de un paciente para estimar el riesgo de enfermedades cardiovasculares mediante el uso de redes neuronales.

El sistema busca apoyar la prevención temprana mediante el análisis de métricas de salud como presión arterial, frecuencia cardíaca, colesterol, edad y otros factores relevantes.

## Objetivo

Desarrollar un modelo predictivo basado en redes neuronales que analice datos médicos del usuario y muestre el nivel de riesgo cardiovascular a través de una aplicación móvil.

## Tecnologías propuestas

* Python
* TensorFlow
* Keras
* Kivy (para la aplicación móvil)

## Funcionamiento general del sistema

1. El usuario ingresa sus datos médicos en la aplicación.
2. El sistema procesa los datos mediante un modelo de red neuronal.
3. El modelo analiza el riesgo cardiovascular del paciente.
4. La aplicación muestra los resultados y métricas de salud.
